¿Qué es HTML?

HTML es el lenguaje para crear páginas web. Usa etiquetas con inicio y fin.

Comandos de HTML - Tabla como en clase

Tabla con Símbolo, Significado, Inicio y Fin - igual a la de tu apunte:

Símbolo Significado Inicio Fin
<html> Indica que empieza un documento HTML <html> </html>
<head> Incluye información sobre el documento <head> </head>
<title> Título que se ve en la ventana del navegador <title> </title>
<body> Introduce la información que aparecerá en la web <body> </body>
<h1> Encabezado de mayor relevancia <h1> </h1>
<p> o <div> Indica que comienza/acaba un párrafo <p> </p>
<br /> Introduce un espaciado entre párrafos <br /> -
<h2>, <h3>... Encabezados de mayor a menor relevancia <h2> </h2>
<img> Inserta una imagen <img src=""> -
<table> Crea una tabla <table> </table>

Estructura básica de un documento HTML:

<!DOCTYPE html>
<html>
  <head>
    Información que lee el navegador
  </head>
  <body>
    Contenido que ve el usuario
  </body>
</html>
